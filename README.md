# E-Borrow — ระบบยืม–คืนของภายในโรงพยาบาล

เว็บแอปทดลองตาม workflow ในภาพร่าง เขียนด้วย HTML + CSS + JavaScript ล้วน
(ไม่ต้องติดตั้งอะไรเพิ่ม เปิดไฟล์เดียวก็ใช้ได้)

## วิธีเปิดใช้งาน

1. แตกไฟล์ทั้ง 3 ไฟล์ไว้โฟลเดอร์เดียวกัน: `index.html`, `style.css`, `app.js`
2. ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์ (Chrome/Edge)
   หรือใน Google Antigravity ให้เปิดโฟลเดอร์นี้แล้วสั่ง preview `index.html`

## บัญชีทดลอง (รหัสผ่านทุกบัญชี: `1234`)

| รหัสพนักงาน | ชื่อ | Ward |
|---|---|---|
| OT1234567 | คุณสมชาย ใจดี | สจม์ 1 |
| OT7654321 | คุณสมหญิง รักงาน | สจม์ 2 |
| N1111111 | พยาบาลวิภา | ENT 1 |
| N2222222 | พยาบาลอรทัย | โรคปอด |

ลองล็อกอินคนละบัญชีเพื่อดูสองฝั่งของการยืม–คืน เช่น
- `N2222222` (โรคปอด) กด **ส่งคืน** ของที่ยืมมา
- แล้วล็อกอิน `OT1234567` (สจม์ 1) จะเห็นปุ่ม **รับคืน** กดได้ (ตามกฎ: ต้องส่งคืนก่อนจึงรับคืนได้)

## แนวคิดการออกแบบ UX/UI (อิงพฤติกรรมผู้ใช้)

ผู้ใช้หลักคือพยาบาล/เจ้าหน้าที่ที่ใช้งานระหว่างเดินงาน มือไม่ว่าง และมักใช้มือถือ จึงออกแบบดังนี้

| พฤติกรรม/ปัญหา | สิ่งที่ปรับ |
|---|---|
| เปิดเว็บมาเพื่อ "ทำงานที่ค้าง" | หน้า Home โชว์ตัวเลข **ต้องส่งคืน / รอรับคืน** แตะแล้วไปจัดการทันที + เลขแดงที่เมนู |
| ใช้มือเดียว/มือถือ | แถบเมนูล่างจอ (จอใหญ่เป็นแถบข้าง) ปุ่มสูง ≥ 44px ปุ่มยืนยันติดล่างจอ |
| ยืมของซ้ำ ๆ จาก ward เดิม | จำ ward ล่าสุด, ปุ่มลัด "ยืมบ่อย", ปุ่ม +/− จำนวน, ปุ่มเหตุผลสำเร็จรูป |
| ตารางกว้างอ่านยากบนมือถือ | เปลี่ยนเป็นการ์ด + แถบความคืบหน้า ยืม → ส่งคืน → รับคืน |
| กดปุ่ม "รับคืน" ไม่ได้แต่ไม่รู้ทำไม | แทนที่ปุ่มจางด้วยข้อความ "รอ ... กดส่งคืนก่อน" |
| คืนหลายชิ้นพร้อมกัน | ปุ่ม **ส่งคืนทั้งหมด / รับคืนทั้งหมด** |
| กดผิด | ไม่ถามยืนยันซ้ำ แต่มี **เลิกทำ (Undo)** 6 วินาที |
| ของค้างนาน | เตือนสีส้ม (≥ 7 วัน) / แดง (≥ 14 วัน) และเรียงค้างนานสุดไว้บน |
| ปุ่ม Back / รีเฟรช | ใช้ `#hash` ทำให้ Back ใช้ได้ และรีเฟรชแล้วไม่หลุดล็อกอิน |

สีสถานะ: **ส้ม** = ต้องมีคนทำต่อ · **น้ำเงิน** = รออีกฝั่ง · **เขียว** = เสร็จแล้ว

## ข้อมูลเก็บที่ไหน?

เวอร์ชันนี้ใช้ `localStorage` (พื้นที่เก็บข้อมูลในเบราว์เซอร์) แทน database จริง
- ข้อดี: ไม่ต้องมี server ทดลองได้ทันที
- ข้อจำกัด: ข้อมูล **ไม่แชร์ข้ามเครื่อง/ข้ามเบราว์เซอร์**
- อยากล้างข้อมูลกลับเป็นค่าเริ่มต้น: เปิด DevTools (กด F12) → Console → พิมพ์
  `localStorage.clear()` แล้วรีเฟรชหน้า

## จุดที่ควรแก้ไขก่อนใช้จริง (เรียงตามลำดับ)

1. **รายชื่อ Ward และผู้ใช้** — แก้ตัวแปร `WARDS` และ `USERS` ที่บนสุดของ `app.js`
2. **Database จริง** — เปลี่ยน 2 ฟังก์ชัน `loadRecords()` / `saveRecords()`
   ให้เรียก API ของ Supabase หรือ Firebase แทน localStorage
   (โครงสร้างที่เหลือไม่ต้องแก้เลย เพราะทุกส่วนเรียกผ่าน 2 ฟังก์ชันนี้)
3. **ระบบล็อกอินจริง** — ตอนนี้รหัสผ่านเป็นค่ากลาง `1234` ฝังในโค้ด ซึ่งไม่ปลอดภัย
   ควรใช้ระบบ auth ของ Supabase/Firebase หรือเชื่อมกับระบบบุคลากรของโรงพยาบาล
4. **แจ้งเตือน** — ต่อยอดให้ ward ปลายทางได้รับแจ้งเตือน (เช่น LINE Notify) เมื่อมีคำขอยืม

## โครงสร้างข้อมูล 1 รายการยืม

```js
{
  id: 1,                      // เลขประจำรายการ
  borrowerName: "…",          // ชื่อผู้ยืม
  borrowerWard: "สจม์ 1",     // ward ผู้ยืม
  fromWard: "ENT 1",          // ยืมจาก ward ไหน
  item: "NSS 100 mL",         // ของที่ยืม
  qty: 1,                     // จำนวน
  reason: "…",                // เหตุผล
  status: "borrowed",         // borrowed → returning → returned
  date: "2026-08-21"          // วันที่ยืม
}
```

สถานะ 3 ขั้นตรงกับ workflow ในภาพ:
`borrowed` (ยืมอยู่) → กด "ส่งคืน" → `returning` (รอรับคืน) → กด "รับคืน" → `returned` (จบ)
